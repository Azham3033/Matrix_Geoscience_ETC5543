The datasets required for the entire project has been compressed and stored in a drive due to large file size. 
The files can be accessed here : https://drive.google.com/file/d/1Ng79ZmtG-Ssd4yhOUoprvve3QhnzEqJ1/view?usp=drive_link

The data files are as follows: 
1) Address Data file. 
2) Municipality wise Data files (Cadastral Data file). 
3) Tas property list document ( based on domain.com.au)


Once the files are downloaded , please follow this path structure in order it run successfully. 
cadastral_data: dataset/LIST_PARCELS_BREAK_O_DAY/list_parcels_break_o_day.shp
address data: dataset/LIST_ADDRESS_POINTS_STATEWIDE/list_address_points_statewide.shp
property listing: dataset/tas_listings_with_price_and_geocode.csv
